# 给我点颜色看看

Koishi 找不同游戏：在同色方格中找出唯一的异色块。

## 安装

```sh
yarn add koishi-plugin-see-color
```

在 Koishi 中启用，并安装 `database` 与 `puppeteer` 服务。

## 指令

| 指令 | 说明 |
| --- | --- |
| `color` | 查看帮助 |
| `color.开始` | 开始游戏 |
| `color.猜 <行 列或块号>` | 猜测异色块 |
| `color.结束` | 结束游戏并公布答案 |
| `color.排行榜 [数量]` | 查看积分排行 |

猜对后方格边长增加，猜错不扣分。
